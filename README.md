# 짝맞추기 게임

50대 이상이 태블릿 웹 브라우저에서 즐기는 패 뒤집기 짝맞추기 게임입니다. 빌드 도구 없이 HTML, CSS, JavaScript만 사용합니다. 제품 요구사항은 [PRD.md](PRD.md)를 참고하세요.

## 실행 방법

**그냥 열기**: `index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다. 서버가 필요 없습니다.

**테스트**: Node.js가 있으면 로직 단위 테스트를 실행할 수 있습니다.

```
npm test
```

**배포 (Vercel)**: 빌드가 없는 정적 사이트입니다. 저장소를 연결하고 Framework Preset은 `Other`, 빌드 명령과 출력 폴더는 비워 두면 루트의 `index.html`이 그대로 배포됩니다.

## 폴더 구조

```
index.html          화면 4개(시작·설정·게임·결과)의 마크업, 스크립트 로드 순서
css/style.css       모든 스타일 (색은 :root의 변수, 글자·터치 크기 기준도 여기)
js/
  config.js         설정값: 난이도, 캐릭터, 점수 상수, 시간 설정   ← 수정은 주로 여기
  game.js           화면과 무관한 로직: 덱 생성, 판정, 타이머, 점수 계산, 결과 객체
  sound.js          효과음 (Web Audio API로 합성, 음원 파일 없음)
  screens.js        화면 전환, 설정 화면, 결과 화면, 색종이
  play.js           게임 화면 흐름: 미리보기 → 덮기 → 플레이 → 종료, 일시정지·나가기
  main.js           화면과 소리를 연결하는 진입점
tests/game.test.mjs game.js·config.js의 단위 테스트
```

- 스크립트는 ES 모듈이 아닌 일반 `<script>`라서 파일을 직접 열어도 동작합니다. 파일끼리는 전역 `MPG` 객체로 연결되며, `index.html`의 `<script>` 순서(config → game → sound → screens → play → main)를 지켜야 합니다. 새 파일을 만들면 `index.html`에 직접 추가하세요.
- `config.js`와 `game.js`는 Node에서도 `require`로 불러올 수 있어 테스트가 가능합니다.

## 점수 계산식

```
시간점수 = min(1500, 1000 × 기준시간 ÷ 걸린시간)
최종점수 = 시간점수 × 난이도 배수 + 목표 달성 보너스(500점)
```

- 기준시간과 난이도 배수는 난이도마다 고정된 값입니다. 목표 시간 슬라이더는 **보너스 여부에만** 쓰이며, 목표를 느슨하게 잡아도 시간점수는 높아지지 않습니다.
- 걸린 시간이 목표 시간 이하이면(같아도) 달성입니다. 걸린 시간은 화면에 보이는 0.1초 단위 값으로 판정합니다.
- 최종점수는 반올림한 정수입니다.
- 예: 중 난이도에서 100초에 끝내고 목표가 100초이면 1000 × 70 ÷ 100 = 700, × 1.5 = 1050, + 500 = **1,550점**

| 난이도 | 기준시간 | 배수 | 패 | 배치 | 미리보기 | 목표 기본값 |
| --- | --- | --- | --- | --- | --- | --- |
| 하 | 40초 | ×1.0 | 12장 | 4×3 | 5초 | 60초 |
| 중 | 70초 | ×1.5 | 16장 | 4×4 | 8초 | 100초 |
| 상 | 120초 | ×2.0 | 20장 | 5×4 | 12초 | 180초 |

## 수정하기 쉬운 설정값

플레이 테스트 후 조정할 값은 대부분 `js/config.js`에 있습니다.

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 패 수, 배치, 미리보기 시간, 목표 시간 기본값, 기준시간, 점수 배수 | `config.js`의 `DIFFICULTIES` |
| 시간점수 상한(1500), 기준 점수(1000), 목표 달성 보너스(500) | `config.js`의 `SCORE` |
| 목표 시간 슬라이더 범위·단위 | `config.js`의 `GOAL_SLIDER` |
| 불일치 패를 보여 주는 시간(1초), 덮는 시간, 결과 화면으로 넘어가는 시간 | `config.js`의 `TIMING` |
| 목표 시간 몇 초 전부터 주황색·알림음을 낼지(10초) | `config.js`의 `WARNING_SEC` |
| 처음 선택값(중, 과일) | `config.js`의 `DEFAULT_SELECTION` |
| 캐릭터 그림(이모지·컬러도형) | `config.js`의 `CHARACTERS` (각 세트 10종 이상 유지) |
| 효과음의 음높이·길이·크기 | `sound.js`의 `SOUNDS` |
| 색, 글자 크기, 터치 영역 | `style.css` 맨 위 `:root` 변수 |

## 디자인·접근성 기준 (PRD 2장)

- 본문 24px 이상, 버튼·안내 문구 28px 이상, 시간·점수 48px 이상
- 모든 버튼·패는 80×80px 이상, 간격 16px 이상
- 글자와 배경의 명암비 7:1 이상. 색만으로 구분하지 않고 ✓ 표시나 문구를 함께 사용
- 탭과 슬라이더만 사용. 같은 패 연속 탭과 두 장이 열려 있는 동안의 다른 패 탭은 무시
- 효과음에는 모두 화면 피드백이 함께 있고, 소리 켜기·끄기 버튼은 모든 화면 상단에 있음 (선택은 같은 탭 세션 동안 유지)
- 움직임을 줄이는 설정을 쓰는 기기에서는 패 뒤집기 애니메이션과 색종이를 줄이거나 끔

## 2단계 확장 지점

저장 기능은 아직 없습니다. 기록·순위를 붙일 때 필요한 자리만 표시해 두었습니다.

- 결과 데이터는 `js/game.js`의 `buildResult` **한 곳에서만** 만듭니다.
  `{ difficulty, character, elapsedSec, goalSec, score, playedAt }` (+ 화면용 `goalMet`, `scoreDetail`)
- 저장은 `js/main.js`의 `onFinish`에서 이 객체를 저장소로 넘기면 됩니다 (`[2단계 확장 지점]` 주석). 화면 코드는 고칠 필요가 없습니다.

## 알아둘 점

- 색종이는 목표 시간 안에 끝냈을 때만 나옵니다. 목표를 넘기면 차분한 완료음과 격려 문구가 나옵니다.
- 앱 이름은 임시로 "짝맞추기 게임"입니다 (`index.html`의 제목과 시작 화면).
- PRD 8장의 미확정 항목(패 수·점수 값, 불일치 시간, 소리 선택 기억 방식 등)은 현재 초안 값입니다.
